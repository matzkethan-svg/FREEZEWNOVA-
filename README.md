# FreezeNova public site snapshot

This repository contains files served publicly by [freezenova.com](https://freezenova.com/) on 2026-11-21:

- `index.html` — homepage HTML, with asset URLs made relative for GitHub Pages
- `assets/index-CQlIW117.js` and `assets/index-Dv8t_w0I.css` — the referenced production bundles
- `emeralds.svg`, `og_image.png`, and `freezenova.ico` — public image and icon assets used by the homepage

These are browser-delivered production files, not FreezeNova's original development source, build configuration, backend, or game source code. Those private project files are not exposed in the public page response. The JavaScript bundle may request data and game content from external services.

GitHub Pages is configured to publish the `main` branch from the repository root.
